# AutoAgent V1 Archive

Everything below this directory belongs to the archived AutoAgent V1 project.
It is retained only for historical reference and comparison with proven
algorithms.

Do not use V1 modules, tests, documentation, build files, Skills, or Evals as
the source of truth for V2. Do not add compatibility layers between this package
and the root V2 package. Modify files in this directory only when the user
explicitly requests V1 archive work.

When inspecting or running V1, use `v1/` as the working directory so its
same-named `autoagent` package is resolved intentionally. V2 work and tests run
from the repository root.
